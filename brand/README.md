# Fine Soil — Brand Kit

A calm visual identity for an independent personal Bible reading companion.

## Brand direction
- **Name:** Fine Soil
- **Tagline:** Read. Reflect. Grow.
- **Primary concept:** Growing Page — an open book with a sprout
- **Personality:** humble, thoughtful, consistent, personal

## Palette
- Deep indigo: `#34457a`
- Gold: `#c58f2a`
- Pale sage: `#eaf0ee`
- Ink: `#1c2a34`

## Typography
Use Georgia (serif) for the wordmark and page headings. Use a clean system sans-serif for interface text.

## Included
- Three logo concepts, each in icon-only and wordmark versions
- Standard and dark-mode-friendly SVG favicons
- Square app icon SVG
- PWA `site.webmanifest`
- `html-head-snippet.html` with favicon and theme-color tags

## PNG exports
Export `fine-soil-app-icon.svg` as:
- `icon-192.png` (192 × 192)
- `icon-512.png` (512 × 512)
- `apple-touch-icon.png` (180 × 180)

Optional favicon PNG fallbacks:
- `favicon-32.png` (32 × 32)
- `favicon-16.png` (16 × 16)

Keep the app icon background opaque. The artwork is inset to allow for platform masking. These are conceptual design assets; check name, domain, and trademark availability before public launch.
